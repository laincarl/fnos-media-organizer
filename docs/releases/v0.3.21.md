## 飞牛影视整理器 0.3.21

首次 GitHub Release，提供 fnOS x86 / amd64 安装包。

### 本版新增

- 整理成功后自动清理空的源文件夹和空上级目录。
- 保留影视库根目录、授权根目录及包含字幕、封面、隐藏文件等内容的目录。
- 任务明细展示已清理目录；清理失败单独提示，不影响成功移动结果。

### 已包含的功能

- fnOS 统一网关与 NAS OAuth 连接、媒体库自动读取、封面和规范检查。
- 可配置命名规则、剧集单集名称、路径差异预览、Shift 连选。
- 顶部任务明细、移动端卡片和按需目录权限引导。
- 原子移动、不覆盖目标、同一文件系统限制和操作日志。

### 安装

下载 `fnos-media-organizer_0.3.21_x86.fpk`，在应用中心手动安装或覆盖升级。扫描无需目录权限；执行整理需要授权对应目录。整理后在飞牛影视重新扫描媒体库。

适配飞牛影视 0.9.8 / mediasrv 0.8.42；使用私有接口，后续版本可能需要适配。构建流水线验证单元测试和 FPK 生命周期，不执行真实 NAS 影视移动。
